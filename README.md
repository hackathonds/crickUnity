# CricUnity

Mobile app for grassroots cricket: matches, verified scorecards, expense
splitting, rewards, social.

Built strictly from `docs/CricUnity_PRD.md` and `docs/CricUnity_Design_Spec.md`,
implemented story-by-story from `docs/CricUnity_Backlog.md`. See `CLAUDE.md`
for the full workflow, non-negotiables, and current stack/commands.
